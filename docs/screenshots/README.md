# README 화면 캡처

촬영 기준일: 2026-11-04. 실제 애플리케이션을 로컬에서 렌더링한 데모 화면입니다.

- 모든 이미지는 가로 1,440px이며, 헤더·주요 콘텐츠·하단 메뉴·푸터가 포함되도록 페이지 높이를 확보했습니다.
- 패널 내부 내용이 잘리지 않도록 캡처 환경에서만 높이 제한과 내부 스크롤을 해제했습니다. 서비스 소스의 스타일과 기능은 변경하지 않았습니다.
- 편집 대상 이미지·문구·로고·PDF 목록은 캡처용 데모 데이터입니다. 실제 사용자 데이터와 브라우저 로그인 프로필은 사용하지 않았습니다.
- 이미지를 잘라 붙이거나 조립하지 않았으며 원본 종횡비를 유지합니다.
